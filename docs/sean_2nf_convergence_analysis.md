## 4. 回答核心问题

### Q1: 需要 J_2N_max 多大?
**J2N=4 足够** (max|dU| < 0.001 MeV at 10 MeV)。J2N=3 基本可用。

### Q2: 需要多大的 J_max?
**J_max=17/2 已充分收敛** (最后一步 0.0008 MeV)。甚至 J_max=13/2 或 15/2 可能已足够 (残差 <0.006 MeV)。

### Q3: Nq 需要多大?
**尚未测试** — 这是下一步。

### Q4: Np=82 是否足够?
**结合能收敛** (20-keV gate), 但散射收敛尚未独立测试。

### Q5: 与 Sean 的 Np=Nq=125, J2N=3, J_max=17/2 对比如何?
我们的 J2N=3, J_max=17/2 已完成。网格 Np=82×Nq=12 远小于 Sean 的 125×125, 但 p/q 解耦后可能足够 (待 Nq 收敛确认)。

### Q6: 哪个轴主导残差?
在低能 (<10 MeV): **J2N** (0.0006 MeV) > J3N (0.0008 MeV), 两者已足够。
在高能 (62 MeV): **J3N** (0.018 MeV) > J2N (0.002 MeV), 高 J 收敛更慢。

### Q7: 哪个轴主导计算成本?
**J3N 梯阶** (229h) >> J2N 梯阶 (10.8h for J2N=3+4)。高 J 扇区 (Nalpha=63) 成本远高于低 J (Nalpha=11-27)。

### Q8: 需要多少资源?
完整 2NF 基准 (J2N=4, J_max=17/2): ~240 wall-hours, ~11,000 core-hours, 12 GB peak RSS。

### Q9: 解耦网格是否更便宜?
Sean 的 125×125 = 15,625 个 q-单元; 我们的 82×12 = 984 个 (16× 更少)。但需要 Nq 收敛确认才能下结论。
